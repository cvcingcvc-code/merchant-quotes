## 未解决问题与人工部署

没有发现阻断指定主流程的问题。交付仍有以下验证边界：

1. 真实 iPhone Safari、Android 浏览器和实际手机文件下载 / 分享菜单尚需人工验收；本次为 Chromium 手机模拟。
2. Docker daemon socket 在该沙箱中不可访问，未完成镜像构建及容器启动实测；提供的 Dockerfile / Compose 是待人工验证的部署路径。已实测部署方式为 `npm ci && npm start`。
3. 不含自动定时备份、账户权限或公网托管。商家试用前人工设置访问密码、HTTPS、持久卷及异机备份，并填写真实商家信息。真实商家数据只能在获其授权后由商家自行录入或恢复。
4. 备份为版本 1 的明文 JSON，单文件最大 8 MB；超出时需单独评估迁移，不应依赖复制运行中的 SQLite 单个文件。

上述部署步骤未在本次任务中执行；没有购买服务、创建付费资源、绑定支付、接触真实客户数据或发布生产环境。
