# 1.1 付费试用交付版验收

日期：2026-10-23（北京时间）。版本：1.1.0。所有验收使用独立临时目录或数据卷中的虚构资料，没有访问真实客户数据。源码位于独立仓库 `merchant-quotes`。

本地 Demo 已完成“新增客户 → 创建报价 → 自动计算 → 中文 PDF → 跟进 → 实际重启后查询”的完整流程。本轮补齐首次正式配置、示例保护、报价复用、资料更正和日备份，并提供试售与交付文档。它具备向首批商家演示和安排付费试用的技术基础；真实手机签收、实际付款和持续使用仍需商家验证。

## 本轮功能与保护

| 场景 | 实际行为与验证 |
| --- | --- |
| 从演示转正式使用 | 首次向导填写商家资料、核对现有数量，配置前先写入完整副本；备份失败不修改资料。新演示商家使用中性条款，旧版商家已有条款供原样核对。 |
| 安全处理示例 | 只根据服务端示例来源标记清理。编辑过或跟进过的记录保留；被自己报价引用的客户保留。不根据旧库中的客户姓名猜测示例。 |
| 完全空白开始 | 需要明确选择并输入“清空全部客户和报价”；旧预览失效、确认错误或备份失败均拒绝写入。此入口仅在首次配置期间提供。 |
| 复制报价 | 新编号、当天日期、待回复、空跟进；原单不变。使用当前客户、商家资料，复制后可先编辑再保存。 |
| 更正单据资料 | 默认冻结已有快照；明确勾选后仅更新当前报价与其 PDF，不改其他报价。 |
| 日备份与下载 | 服务启动、工作台读取和运行中每小时检查；北京时间每天最多一份，保留最近 14 份。配置前与恢复前副本不随日备份轮换。 |
| 备份兼容 | 导出 v2；接受旧 v1，旧记录视为已使用资料，不带可自动清理的示例身份。校验金额、关联、版本与 8 MB 大小上限。 |
| 设备与多次访问 | 手机主要操作通过浏览器验收。编辑报价有版本检查；内联新增客户后仍沿用原草稿版本，拒绝覆盖其他设备已保存的修改。 |

## 已执行的完整演示

手机视口中移除五组未修改的虚构示例，填写“试售验收图文工作室”，新增“试售虚构客户”。新建两行报价：`3 × 19.90 = 59.70`、`1.5 × 100.05 = 150.08`，合计 **209.78 元**。导出 PDF 后用 `pdftotext` 检查中文与金额，并查看页面渲染。

保存成交、下次跟进与备注，更正客户及商家资料后，明确更新当前报价快照，再导出中文 PDF。复制成独立新单，核对原单仍成交、副本待回复、编号不同且无原跟进历史。下载日备份与配置前副本，执行 v2 手动备份恢复。随后实际终止并启动新服务进程，刷新文档重新取数，确认商家已配置、1 位客户、2 份独立报价、金额与跟进仍在 SQLite 中。

原始 MVP 演示也重新执行：新增、搜索和编辑客户，创建两行报价，下载 PDF，跟进成交，备份恢复并实际重启。四个主要页面在 320、390、768、1440 px 宽度下无横向溢出。

## 可用性结论与剩余人工步骤

没有发现阻断已验收主流程的问题。以下工作必须在真实交付中完成：

1. 在商家自己的电脑或已有 Docker 主机安装，确认磁盘、端口、防火墙、同一 Wi-Fi 可达和断电重启方式。本次未验证 Windows / macOS 的安装，也未代购设备或云服务。
2. 使用真实 iPhone Safari 或 Android 浏览器下载并打开 PDF、选择备份文件，按交付单签收。本次只有 Chromium 手机模拟。
3. 设置访问密码，核对真实商家抬头与条款，安排每天营业结束导出并保存到其他设备。日备份是当天首次快照，不包含此后所有新修改，也不能抵御同一磁盘损坏；关机期间不生成备份。
4. 如需公网远程使用，由负责人配置已有持久主机、HTTPS、证书、域名及维护责任，只运行一个应用副本。没有在本次任务中公开发布服务。
5. 按双方确认的服务范围向商家报价并记录真实付款、第 3 / 7 天实际使用及交付成本。文档中的 399 元是建议测试价，尚无付款、留存或收入证据。

本轮在交付准备与验收范围结束后停止功能开发。未添加多租户、支付、AI API、获客、分销或会员功能。
