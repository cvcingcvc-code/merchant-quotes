# 电脑启动、手机打开

这条路径适合当面向商家演示，无需云服务。需要一台安装 Node.js 24 的电脑，以及与它连接同一 Wi-Fi 的手机。下面命令应在你自己的电脑运行；云端任务容器的内网地址无法供你的手机直接访问。

1. 下载并解压源码 ZIP，打开其中 `merchant-quotes` 目录的终端。
2. 首次安装依赖，之后启动：

```bash
npm ci
npm run demo:lan
```

首次启动时，若没有 `.env` 和访问密码，会自动生成本机 `.env`。用文本编辑器打开该文件，找到 `APP_PASSWORD`。用户名固定为 `merchant`。脚本不会覆盖已有 `.env`，已有密码不足 12 位时会提示修改后重新启动。

终端显示手机可访问的局域网地址，如 `http://192.168.1.8:3000`。保持终端打开，在同一 Wi-Fi 的手机浏览器输入显示的地址，使用上述账号和密码登录。若显示多个网卡地址，优先选择 Wi-Fi 网卡对应地址。电脑防火墙应允许应用在专用网络接收连接；访客 Wi-Fi 的设备隔离可能阻止访问。

## 五分钟人工检查

- 新增一个虚构客户，然后搜索并编辑它。
- 为客户创建报价：`3 × 19.90` 加 `1.5 × 100.05`，应合计 `¥209.78`。
- 下载中文 PDF，使用手机文件应用打开，确认中文、两项明细和合计。
- 改成“已成交”，保存下次跟进日期与备注。
- 电脑按 Ctrl+C 停止，再运行 `npm run demo:lan`；刷新手机，检查上述数据仍在。
- 在“商家设置”导出备份，确认手机可选择下载的 JSON 文件并进入恢复确认界面。

这一步需要真实手机操作；Chromium 的手机模拟截图不能代替真机验收。不要使用未获授权的真实客户资料。

## 连不上时

1. 先在电脑打开 `http://127.0.0.1:3000`，确认服务已启动。
2. 核对手机与电脑连接同一局域网，手机使用终端显示的 IPv4 地址。
3. 检查专用网络防火墙、访客 Wi-Fi 隔离，以及地址是否因换网络而改变。
4. 若端口被占用，在 `.env` 修改 `PORT` 后重新启动。

这些地址仅供局域网演示。远程商家试用需要你自己的可达主机或受支持的预览转发入口，以及 HTTPS。未在本次任务中创建公网服务。
